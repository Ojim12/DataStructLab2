In the delimiter checker each item in the stack represents an opening deleimiter that has not been closed yet like (,[ or {. We need the most recently pushed delimiter because the last opener we se has to be closed before the ones tha came before it. For example in ([)] we first push ( and then [, when we get to ) we have to check [ since it was the most recent opener. Because ) doesn not match [ the expression has mismatched delimiters.
In the postfix evaluater, each stack item represents either a number or a result from an operation that might be used later. The most recently pushed values are needed because an operator alwsy works with the two most recent operands. For example in 8 3 2 * + the * uses 2 and 3 first givng 6 that 6 is then pushed back onto the stack and the + uses 6 and 8 to get 14.
LIFO is required in both algorithms because the newest information js the information is the information that needs to be handled first. For delimiters the newest opening brackets must be matched before an older one can be closed.For posyfix expressions the newest operands are the ones an operator needs first, if we used the oldest item instead we could match the wrong delimiter or use the wrong operands and get an incorrect result.
